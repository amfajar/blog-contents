    - [ ] dbt tests = automated checks (no nulls, unique keys, valid ranges)

### Day 8

#### Session 1 — Technical (60 min)

- [ ] SQL: **gaps and islands problem** — a classic advanced SQL pattern
    - [ ] Problem: find consecutive sequences in data (e.g., consecutive days a user was active)
    - [ ] Solution approach: `ROW_NUMBER()` subtraction trick
    - [ ] Practice: find all sequences of consecutive days where daily revenue > average
    - [ ] Record the gaps-and-islands pattern in `SQL-Basics.md`

#### Session 2 — Analytical/Business (60 min)

- [ ] Learn the concept: **slowly changing dimensions (SCD)**
    - [ ] What is a dimension that changes over time? (e.g., a product changes its category)
    - [ ] SCD Type 1: overwrite old value (simple, loses history)
    - [ ] SCD Type 2: add a new row with effective dates (preserves history)
    - [ ] Why BI Analysts care: SCD Type 2 is why you see `valid_from` and `valid_to` columns in data warehouses
- [ ] Save in `Business-Concepts.md` under "Data Modeling Concepts"

### Day 9

#### Session 1 — Technical (60 min)

- [ ] SQL: **sessionization** — grouping user events into sessions
    - [ ] A session = a series of events where no gap between events exceeds 30 minutes
    - [ ] Approach: use LAG() to find time gaps, then CUMSUM to assign session IDs
    - [ ] Practice: given a table of page views with timestamps, assign a session_id to each row
    - [ ] Record this pattern in `SQL-Basics.md` under "Advanced Patterns"

#### Session 2 — Analytical/Business (60 min)

- [ ] Learn the concept: **star schema vs snowflake schema**
    - [ ] Star schema: one central fact table surrounded by denormalized dimension tables
    - [ ] Snowflake schema: dimension tables are normalized (split into sub-dimensions)
    - [ ] BI tools like Power BI and Tableau work best with star schemas
    - [ ] Draw both schemas for your e-commerce database
- [ ] Save in `Business-Concepts.md` under "Data Modeling Concepts"
